# Characterize a blind spot instead of agreeing it exists

**Measured 2026-08-17 on a behaviour-preserving module move.** Three independent
instruments agreed the moved bodies were unchanged. **All three normalized
whitespace first**, and the merge named that as their shared hole — honestly,
and **without a candidate for what could hide in it.**

⇒ ***A hole named without a shape invites agreement, which is worth nothing.***
**Whitespace normalization preserves text, so what survives it is identical text
that MEANS something different in the new location** — and for a module move
that is exactly two things, both countable:

```
#[cfg] context        2 in the child = 1 moved + 1 new scaffolding    balanced
path-relative refs    crate:: 11 (absolute)   super:: 1   self:: 0
```

⇒ ***Eleven of twelve references are absolute, so their meaning cannot depend on
where the code lives.*** **That is a structural reason the move is safe, and it
does not depend on the comparison at all** — the instruments show the text did
not change; this shows the text's meaning could not have.

⇒ ***Beating a triple-agreement argument means arguing from a different
premise, not re-running it a fourth time.***

## SAY "NEARLY EMPTY", NOT "EMPTY"

`use super::*` binds against the new parent where the code previously sat *in*
that parent, so a name reachable in both could rebind. **The compiler errors on
ambiguous glob resolution**, so a silent rebind needs the name present in
exactly one module at each site. ⇒ **Name the residual mechanism and why it is
narrow** — a characterization that overstates its own completeness is the thing
it was written to replace.

## A ZERO ROW IS A SENTINEL ONLY BECAUSE THE NON-ZERO ROWS EXIST

An all-zero census row for a new file asserts absence. ⇒ **It reds when a later
addition makes a count non-zero — but only if the counters detect that pattern,
which is established by the roster's OTHER rows.** **A zero row read in
isolation proves nothing; read against a populated roster it is a real
sentinel.** Say which, because the row looks like decoration either way.
