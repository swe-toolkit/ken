# A corrected census can keep a wrong citation that mis-scopes the stated gap

**Measured 2026-08-16 on `f97ffb87a..7d904d7eb`**, a recut after a first cut was
rejected for supplying lemmas at the **dual** polarity of what the consumer
accepts.

⇒ **A third census by grep confirmed the corrected polarity.** ⇒ **It also
found the replacement citation lists a site the operator does not appear at,
inside a function that does not call the operator at all** — and names that
function as a **route to** the operator when it is a **leaf the operator's own
arms call.** The direction is inverted.

⇒ ***Harmless for what was delivered, decisive for what was not.*** The same
block names an undelivered eliminator *"needed to descend into"* that function
— and since the function contains no such operator, descending there needs a
**different** lemma entirely. ***A mis-scoped gap statement is how the first
cut's error happened one level up***, so the recut reproduced the shape at
smaller scale while fixing the instance.

⇒ **Check the NOT-DELIVERED paragraph with the same care as the delivered
set.** It is the part that survives into the successor's frame, and it is
written last, when the census that would falsify it feels already done.
