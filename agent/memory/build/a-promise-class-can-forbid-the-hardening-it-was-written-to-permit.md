# A promise class can forbid the hardening it was written to permit

**Measured 2026-08-15 on `674b2a68e...699ae8da3`.**

> *"Promise class: transition sentinel. Retirement or an authorized boundary
> repair must rewrite this route comparison rather than preserve its current
> exact outcomes."*

An arm-order inversion **preserves both outcomes exactly** — it changes
sequencing, not the comparison. ⇒ **Read literally, the sentence's operative
contrast puts a hardening edit on the `preserve` side, which is the side it
exists to forbid.**

⇒ ***The sentence does two jobs and states one.*** It gives a **requirement on
future semantic change** (*on retirement, rewrite this*); what a hardening needs
is the **licence underneath** (*the exact outcomes are not the promise; the
comparison is*). The licence is implied by the class name and never written.

⇒ ***When asked whether a promise class survives an edit, check which side of
its own contrast the edit falls on*** — not whether the edit feels consistent
with the class's intent. **A class that has to be interpreted is not governing.**
The repair is one clause naming what edits are permitted, not a new class.

## RUN THE EXPERIMENT THAT WAS NAMED AND NOT RUN

The same merge recorded a residual as *"a reading of state flow, not a
measurement"*, and said inverting the arm order would close it outright.

```
depth=2 FIRST=unexcluded crossings=0   SECOND=excluded crossings=2
depth=3 FIRST=unexcluded crossings=0   SECOND=excluded crossings=2
```

⇒ **The empty observation survives being first**, on a compile nothing could have
memoized, **and the anchor survives being second.** ⇒ ***When a reviewer names
the exact experiment that would close their own residual and does not run it,
that is the highest-value thing available*** — the design work is done, the cost
is one edit and one targeted run, and the result converts someone else's
carefully-hedged reading into a fact.

**Say that the measurement AGREED with the reading.** The value is removing the
hedge, not overturning anyone; a confirmation reported as a confirmation keeps
the next hedge honest instead of defensive.

## DO NOT MANUFACTURE A DISCREPANCY FROM A HALF-REMEMBERED RUN

The excluded arm recorded 2 crossings; an earlier probe by the same reviewer, on
a similar fixture through a **different** control, had printed more. ⇒
**Different control, different symbol, possibly different compile count — the
numbers are not comparable without re-measuring both under identical
conditions.** Reporting that gap as a finding would have been an artifact of the
reviewer's own note-taking.
