This inventory records the backend's tests and the reusable fixture, mutation,
counter, denominator, and source-oracle surfaces that later moves must
preserve.

## Boundary and selectors

The domain is every Rust file below
`crates/ken-runtime/src/cranelift_backend/` plus
`crates/ken-runtime/src/boundary_value_clif.rs`. Literal tests use the
whitespace-tolerant selector `^\s*#\[test\]`, followed through
attributes to the next function. It selects 716 tests, including
ignored tests. It cannot see generated tests, nonstandard test attributes,
doctests, or external integration tests.

Property classes are a reproducible lexical triage. A test is a mutation
control when its body references a declaration selected by
`(?i)mutation` or its name states a mutation/corruption/omission;
otherwise it is end-to-end when it calls one of the named compile, run, or
object-emission entry points; the remainder is domain unit. Injection points
are the named production/helper calls in the body, falling back to the owning
module. This classification cannot prove dynamic reachability and can
under-classify a helper that hides the real injection point.

Reusable fixtures use function names containing `fixture`. Mutation
surfaces use type or function names containing `mutation`. Counter and
observation candidates are uppercase Rust `static` declarations. These
name selectors can miss neutrally named helpers and can over-enter a static
that is state rather than a count. Source oracles are lines containing
`include_str! / include_bytes! / read_to_string / CARGO_MANIFEST_DIR / source_oracle`.
Denominator candidates are tests containing explicit positive/nonzero
assertions or a fixed nonzero `.len()` equality; other semantic
non-vacuity arguments are not visible to that lexical selector.

## Caveat guard

The landed
`identifier_census_caveat_tracks_inline_cfg_test_region_count` control is
fixed for its exact selector: in `lowering/core.rs`,
`^\s*#\[cfg\(test\)\]` selects 322 bare test regions. The rationale's
test-active population is 340 because
`^\s*#\[cfg\(any\(test,` selects 18 additional regions. The guard cannot
see that second population grow. The entry is therefore fixed but partial;
a bare 322 is not a completeness claim.
