## The selected representation (Architect ruling — do not redesign it here)

The planner shall issue one first-class checked-IH application relation before
carry, `CheckedIhApplicationCapsulePlan`. It is compiler-only and binds, as one
closed record:

- source specialization 1, closure seat 671, worker body 662, declared arity
  one, source record 608, and captures 0..7 in planner ordinal order;
- the exact inner route `RawWorker` — hence `raw_worker_calls` target resolution
  and no generated-context suffix;
- destination specialization 2 / body 941 and the full nested application path to
  Host-Vis invocation/application `147/146`;
- origin 144 and its destination `Parameter(0)` coordinate as the sole
  `HostResult` explicit argument;
- the exact application-result consumer/control continuation to which the nested
  call returns.

The descriptor carries stable plan identities and a target recipe ONLY — no
runtime tag, function pointer, closure descriptor, environment pointer,
`FuncRef`, Cranelift `Value`, or inferred target. A `FuncRef` remains
Function-local: the eventual consuming Function must declare/resolve body 662
afresh from the capsule's exact `RawWorker` recipe. The outer body-941 call
remains authoritative — this design does NOT retarget application 146 from body
941 to body 662; the capsule is installed as a typed nested-call capability in
the exact generated-context variant body 941 enters after the matching HostResult
arrives (its placement, not a competing second mechanism).

At lowering, immutable plan data is not itself emission permission. Exact
destination selection plus successful local reconstruction mint a separate
non-`Clone`, non-`Copy` `CheckedIhApplicationAuthority`; only that move-only
authority may emit the nested body-662 call, through the existing
`call_static_worker_with_inputs` contract (explicit origin-144 `HostResult`
first, record-608 captures 0..7 next, no suffix, target from `raw_worker_calls`),
reading status and Trap before Result. Only the non-trap Result may become
private compiler-local `CheckedIhApplicationResult` and feed the natural
`ResourceBodyResult` consumer. `CheckedIhCapturedEnvironment` remains a different
private role and must be unrepresentable as `CheckedIhApplicationResult`;
`CheckedIhEnvironmentTransport` stays environment-only.
