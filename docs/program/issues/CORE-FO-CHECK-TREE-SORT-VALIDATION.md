## The measurement, which is not in dispute

Language QA built a literal checker probe and ran it:

```
ForallWorld (ForcingP Bound(0) Bound(0) -> ForcingP Bound(0) Bound(0))
  with ForallRight { eigen: Parameter(0) }, then ImpRight, then Init
```

The second `Bound(0)` is an **object** slot and the eigenparameter is a
**world**. **`check_cert` returned `true`.**

`Form` and `QTerm` carry no sort tag, `check_tree` validates no sorts, and
`Init` closes the derivation syntactically. **Freshness of the eigenparameter is
a condition on the derivation's variable discipline and says nothing about which
sort slot a parameter lands in.**

## Why this is hardening and NOT a soundness fix

**Architect ruling `evt_71g1xf5vkf1ek`: route FO is not unsound today, and the
reason is structural rather than incidental.**

`check_cert` is total over `Form`. **`Form` is strictly larger than the image of
`embed` on `IForm Sigma`**, and the probe above lives in that excess — it is
hand-constructed directly in the target language and no `IForm` maps to it.
`quote_iform` refuses anything that is not an in-scope object `Var` of the
declared sort (`FoBoundary::IllScopedOrIllSorted`), so **`IForm` has no world
variables at all**; worlds do not exist until `embed` introduces them. The
discharge composition only ever evaluates `check_cert (embed Sigma f) pi` for
`f : IForm Sigma`.

⇒ **The accepted-but-ill-sorted certificates exist in the checker's domain and
are unreachable from the route.**

> **What this node would buy, stated precisely so it is not oversold: it moves
> the guarantee from the CALLER into the CHECKER.** Today any caller handing
> `check_cert` a `Form` obtained some other way than `embed Sigma f` loses the
> property **with no diagnostic** — the checker accepts and says nothing. That
> is a real sharp edge for adapter work and for anything that constructs `Form`
> directly. It is not a hole in the route as it exists.

## It does not force a spec change, and no node should be spent on one

`checker_soundness` is stated over all of `Form` as `classically_valid q`, and
`23 §4.3` defines `Derivation` as the indexed family generated by **exactly the
same rules** — so an ill-sorted `q` that `check_cert` accepts is also one the
untyped calculus derives, and **the theorem remains provable as stated.**

The burden that would otherwise have been threatened sits in
`embedding_adequacy`, which is quantified over `f : IForm Sigma` — precisely the
well-sorted family. **The layering already puts the obligation where the
discipline exists.**

## Deliverables

**`D0` — decide the carrier.** Either a sort tag on `QTerm`/`Form`, or a
sort-checking pass in `check_tree` over the existing untyped representation.
**Front-load this**: a tag changes the datatype the two unproved theorems are
stated over, which is a materially different cost from a validation pass that
leaves the type alone. **Say which theorem statements move, if any.**

**`D1` — the validation.** `check_tree` rejects a derivation that places a
parameter of one sort into a slot of another. The QA probe above is the
positive control and must flip from accepted to rejected.

**`D2` — the caller obligation is retired or restated.** If validation is
complete, the comment at the `check_cert` site saying the guarantee belongs to
the caller becomes false and must be corrected. **If it is partial, say exactly
which residual the caller still owns** — a partially-honest domain that reads as
fully honest is worse than the current state.

## Acceptance criteria

**`AC-1`.** The QA probe is a landed control that **fails before the change**.

**`AC-2`.** No behavior change for any `Form` in the image of `embed` on
`IForm Sigma`. This is a domain restriction on the excess, not a semantic change
to the route.

**`AC-3`.** No `proved` for FO and no slice widening.

**`AC-4`.** No new kernel primitive and no trusted axiom.

**`AC-5`.** No-regression, in CI (`COORDINATION §12`).
